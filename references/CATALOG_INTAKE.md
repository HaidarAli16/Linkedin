# Reference catalogue intake

When Haidar supplies a LinkedIn reference catalogue, place each source in `assets/reference-catalog/`, name it descriptively, and add it to the concise coded index. The current index is [LINKEDIN_CATALOG.md](../assets/reference-catalog/LINKEDIN_CATALOG.md). A contact sheet is optional when the catalogue becomes too large to scan from the index.

Treat references as visual vocabulary, not layouts to trace. Extract hierarchy, contrast, material, density, image treatment, and diagram grammar. Do not copy handles, profile names, page counters, UI chrome, or exact text from reference posts.
